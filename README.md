# Fractol

A fractal visualization program using MiniLibX.

## Description

This project renders beautiful fractals like Mandelbrot and Julia sets.

## Features

- Mandelbrot set
- Julia set with custom parameters
- Zoom with mouse scroll
- Move with arrow keys
- Color changing

## Usage
```bash
# Compile
make

# Run Mandelbrot
./fractol mandelbrot

# Run Julia (default)
./fractol julia

# Run Julia (custom values)
./fractol julia -0.7 0.27015
```

## Controls

- **Mouse Scroll**: Zoom in/out
- **Arrow Keys**: Move around
- **ESC**: Exit
- **C**: Change colors
